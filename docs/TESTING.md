# 手机安装测试（FfalconPush 0.2.1）

## 范围与安装

用户已报告此前安装包能正常使用；设备版本和逐项场景未补充。本轮由用户自行覆盖安装，确认新版 UI 和功能回归；Agent 不连接或操作电视。

- APK：`artifacts/FfalconPush-0.2.1.apk`（仅本地生成，公开仓库不包含 APK），桌面名称为 `FfalconPush`，图标为雷鸟几何鸟标的矢量重绘，主界面不显示应用名称。
- 手机要求：Android 8.0 / API 26 及以上；安装到手机，不是电视。
- 包名保持 `io.github.lichen.raybirdpush`，versionCode `4`。内部包名保留旧拼写是为兼容升级及保留电视 IP 记录，不是产品英文名。请直接覆盖安装旧实验版，无需卸载；实际覆盖升级仍待手机验证。
- release 构建、非调试模式、未开启 R8，使用构建电脑的本机 debug 证书，仅供实验。不承诺在其他电脑重建后具有相同签名。若更新提示签名不一致，请停止并核对证书，不要擅自卸载已有应用。
- 本轮产物的 SHA-256、证书检查和测试汇总位于 `artifacts/`；它们是本地构建产物，不入库。

## 第一次完整测试

1. 确认测试对象是你自己的或已获授权的电视。只输入这一台的 IP，不扫描整个网络。
2. 手机连接与电视互通的 Wi-Fi/以太网，打开 App；只打开界面不会发起连接。主屏只有电视、APK 卡片和上箭头推送按钮，没有说明文字或本机 IP。
3. 点电视图形，选择历史地址，或输入电视 IPv4 后点勾号；垃圾桶可忘记记录。只支持常见私有 IPv4（10/8、172.16/12、192.168/16），暂不支持 IPv6、主机名、末段 0/255。多个局域网接口时在此面板选择网络；只显示 Wi-Fi/以太网名称，不显示手机 IP，不扫描设备。
4. 点 APK 图形进入系统文件选择器，选择完整单 APK（≤512 MiB，不支持 APKS/XAPK/AAB/split）。卡片显示图标、应用名、版本和大小；再次点卡片可核对真实包名，点文件夹图形更换。
5. Android 13+ 点击推送时可弹出系统通知授权；拒绝不等于无法传输，请在 App 内查看和取消。回调不会重复发起推送。
6. 点圆形上箭头。只有此时才联网并发安装请求；按钮变为方形停止符号，可取消传输。准备文件期间同一位置可取消读取。成功握手后保存连接记录，不必等安装成功；失败连接不会记入历史。
7. 电视弹出确认后，遥控器 **右 → 选“同意” → 按确认**。App 不代按确认，不修改电视设置。
8. 观察光点、进度环及必要状态短提示；等待同意时仍显示“右 → 同意 → 确认”。只有匹配安装回执才出现完成勾号；未知结果会显示“结果未知 · 请到电视核对”，不能误认为成功。主屏不显示日志或 HTTP 技术字段。
9. 会话结束后 APK 缓存会删除，再次推送需重新选文件。电视 IP 保留，重开默认选中最近地址但不得自行联网。必要时点结果提示查看原因，点电视卡片内的分享图形手动导出脱敏诊断，文档图形查看第三方许可。

## 失败如何判断

| 现象 | 含义 / 下一步 |
|---|---|
| 连接/握手失败 | 检查指定 IP、网络互通、多屏互动是否可用；不等于 APK 不兼容。不会自动尝试其他 IP 或开 ADB |
| 一直等待同意、尚无 HTTP 请求 | 确认遥控器选择了同意。90 秒无状态推进会超时；可能是未同意、网络问题或固件拒绝 LAN URL，单凭这个现象不能确定原因 |
| 有 HTTP 写出但无安装回执 | 写出不是电视保存或安装成功。收到协议下载/安装进度后，各阶段最多 180 秒；不要把 HTTP 100% 当成功 |
| 安装阶段断链/超时，或文件已写完但没完成回执 | 显示“结果未知”；先去电视核对，不自动重发、不卸载、不回滚 |
| 收到失败状态 | 可能涉及版本、签名、架构、minSdk 等；当前协议不能可靠细分所有电视错误原因。不声称可绕过 Android 校验 |
| 点击取消 | 停止手机的 TCP/HTTP/服务；不能撤销电视可能已开始的安装 |

当前只实现 **LAN HTTP**。若电视接受请求但从不访问手机 URL，请分享脱敏诊断及“是否已同意”的人工观察；此时先定位原因，不能声称免 ADB 方案已支持，也不会自动切换 ADB。

## 新版回归清单（待用户逐项执行）

- [ ] 直接覆盖旧包后名称/图标已更新，电视记录保留；无需卸载。
- [ ] 主屏无应用名、介绍、本机 IP 或日志；图形控件可理解，动画流畅。
- [ ] 小屏/大字体/旋转可操作，TalkBack 能读出电视、APK、推送及取消控件。

- [ ] 同意后完整安装；实际电视安装结果与匹配回执一致。
- [ ] 拒绝后立即结束，不自动再次弹窗。
- [ ] 不操作电视：有限时间超时，服务/通知退出。
- [ ] 手动输入一个明确属于自己环境的错误地址：有限失败，不遍历其他地址。
- [ ] 已同意但下载不可达：无请求/不完整请求不会误报成功。
- [ ] 下载中断网/切换 Wi-Fi：有期限、最终结果不伪报。
- [ ] App 切后台、锁屏、旋转：不会重复发送；结果及取消可查看。
- [ ] 取消 APK 读取、连接中取消、下载中取消、安装阶段取消：手机传输关闭，不声称电视已回滚。
- [ ] 签名冲突、旧版本或架构不兼容：如实失败/未知，不自动卸载电视应用。
- [ ] 第二次推送、同包名再次推送：旧完成回执不影响新任务。
- [ ] 杀死并重开 App：恢复最近 IP，不恢复或重发任务；此前安装结果需电视核对。
- [ ] 最近记录选择/忘记、App 重开后恢复；无备份或诊断泄露 IP。
- [ ] 结束后通知消失；下次任务能重新建立监听，未遗留常驻服务。
